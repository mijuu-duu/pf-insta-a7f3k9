====================================================
 단서 인스타 — 설치 및 사용 안내
====================================================

[폴더 구성]
  index.html            앱 본체 (화면·기능 전부 이 파일 안에 들어있음)
  logo.png              ★ 상단 가운데 인스타그램 로고 (여기에 넣으세요)
  manifest.webmanifest  앱 설치 기본값 (앱 이름 = Instagram)
  sw.js                 오프라인 캐시 + 최신 파일 우선
  icons/                앱 아이콘 (192, 512)
  _headers              Netlify 전용 응답 헤더 (다른 서버에서는 무시됨)
  robots.txt            검색엔진 수집 차단
  README_설치안내.txt   이 파일

----------------------------------------------------
0. 로고 바꾸기
----------------------------------------------------
 로고는 index.html 안에 이미지째 들어 있습니다.
 그래서 폴더에 logo.png 가 없어도, 인터넷에 올려도, 폰에 설치해도
 어디서나 똑같이 보입니다. (logo.png 파일은 이제 없어도 됩니다)

 지금 들어있는 로고는 글꼴로 비슷하게 만든 "근사본" 입니다.
 (실제 인스타그램 로고 파일이 아닙니다)

 [진짜 로고로 바꾸는 법]
  (1) 관리자 모드 > "상단 로고 이미지" > 로고 선택 > PNG 고르기
      - 흰 여백은 자동으로 잘라서 꽉 차게 맞춰줍니다
  (2) 맨 아래 "새 index.html 만들기" 를 눌러 파일을 만듭니다
  (3) 그 파일로 폴더의 index.html 을 교체해서 배포합니다
      → 이제 모든 기기에서 새 로고가 보입니다

 · (2)(3) 을 하지 않으면 로고를 올린 그 기기에서만 바뀝니다.

----------------------------------------------------
1. 미개통 안드로이드에 앱으로 설치하기
----------------------------------------------------
준비물: 미개통 안드로이드 1대

 (1) 폰에 HTTP 서버 앱을 설치합니다.
     - Play 스토어에서 "Simple HTTP Server", "KSWEB", "Web Server" 등으로 검색
     - 플레이스토어는 SIM 없이도 Wi-Fi + 구글 계정만 있으면 사용 가능합니다.

 (2) 이 폴더를 통째로 폰 내부저장소에 넣습니다.
     예) /storage/emulated/0/Download/단서_인스타_배포용/

 (3) 서버 앱에서
     - 루트 폴더(Document root) = 위에서 넣은 폴더
     - 포트(Port) = 8080
     로 설정한 뒤 START 를 누릅니다.

 (4) 크롬 주소창에 아래 주소를 입력합니다.
        http://localhost:8080/
     ※ 반드시 localhost 로 접속하세요. localhost 로 열어야만
        크롬이 "앱 설치"를 허용합니다. (IP 주소로 열면 설치 불가)

 (5) 크롬 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가" 를 누릅니다.
     홈 화면에 Instagram 아이콘이 생깁니다.
     첫 실행 이후에는 서버를 꺼도 앱이 열립니다.
     (새 파일로 업데이트할 때는 서버를 다시 켜야 합니다)

 · 아이폰은 사파리로 같은 주소를 연 뒤
   공유 버튼 → "홈 화면에 추가" 를 누르면 됩니다.

2. 인터넷에 올려서 설치하기 (Netlify)
----------------------------------------------------
 (1) https://app.netlify.com/drop 접속
 (2) 이 폴더를 통째로 드래그해서 올립니다.
     (폴더 안의 파일들이 아니라 "폴더" 를 그대로 올리세요)
 (3) 받은 주소를 폰 크롬/사파리로 열고 "앱 설치" 또는 "홈 화면에 추가"
 · robots.txt 가 들어있어 검색에는 노출되지 않습니다.
   다만 주소를 아는 사람은 누구나 볼 수 있으니 주소 관리에 주의하세요.

3. 관리자 모드 들어가기
----------------------------------------------------
 · 손님 모드   : 홈 화면 왼쪽 위 ＋ 버튼을 5초간 길게 누르기
                → 관리자 모드로 바뀌면서 관리자 화면이 열립니다.
 · 관리자 모드 : ＋ 버튼을 짧게 누르면 바로 관리자 화면
 · 관리자 화면 오른쪽 위 "손님 모드" 를 누르면 다시 손님으로 돌아갑니다.
   (관리자 모드일 때는 화면 오른쪽 위에 "관리자 모드" 표시가 보입니다)

 [관리자 탭 구성]
   게시물  피드에 올라가는 글. 작성자·사진·캡션·좋아요·시간·댓글, 순서 이동
   사용자  내 계정(앱 주인) 한 개만. 프로필·아이디·소개·팔로워·인증배지
   DM      대화 상대와 메시지. "나"가 보낸 말은 오른쪽(보라색)에 표시
   스토리  내 계정 외의 인물들. 목록 순서 = 손님 화면 상단 스토리 순서

 [스토리 탭 규칙]
   · 인물 하나 = 계정 하나 = 스토리 하나 입니다.
   · 스토리 사진이 있으면  → 무지개 링, 누르면 스토리가 열립니다.
   · 스토리 사진이 없으면  → 회색 링, 눌러도 아무 일도 없습니다.
   · "스토리만 삭제" = 사진·시간만 지움. 계정과 그 사람의 게시물·댓글·DM은 남습니다.
   · "이 계정 삭제"  = 계정 + 그 사람의 게시물·댓글·DM 까지 전부 삭제됩니다.

 [손님 화면에서 되는 것 / 안 되는 것]
   되는 것   스토리 보기(좌우 탭으로 이동), 게시물·댓글 보기, 프로필 보기, DM 읽기
   안 되는 것 릴스·검색 탭, 상단 노트·하트, 좋아요·댓글 쓰기, 메시지 보내기
             (전부 눌러도 아무 반응이 없습니다 — 보기 전용)

4. 내용 저장 규칙 (중요)
----------------------------------------------------
 · index.html 안에는 "파일에 들어있는 내용"(DATA_VERSION + 내장 데이터)이 있습니다.
 · 관리자 모드에서 고친 내용은 그 폰 안에만 저장됩니다.
     - 같은 파일(같은 DATA_VERSION)로 다시 열면 → 폰에서 고친 내용이 우선
     - 새 파일(DATA_VERSION 이 다름)을 설치하면 → 폰 내용을 지우고 파일 내용으로 시작
   관리자 화면 "백업 / 복원" 칸에 지금 상태가 표시됩니다.
     "파일 내용과 같음" / "이 기기에서 수정한 내용 있음"
 · 사진은 파일이 아니라 데이터로 저장됩니다. 저장소는 IndexedDB 를 쓰므로
   폰에서도 수십 MB까지 들어갑니다. (예전 방식인 localStorage 는 5MB 정도에서
   막혀서 사진이 저장되지 않았습니다)
   사진은 업로드할 때 자동으로 축소되며, 현재 용량은
   "백업 / 복원" 제목 옆에 KB 로 표시됩니다.

 · 사진이 안 올라갈 때
   - "이 사진 형식은 열 수 없습니다" 가 뜨면 아이폰 HEIC 등 폰 전용 형식입니다.
     갤러리에서 JPG 로 저장한 뒤 다시 고르세요.
   - 사진을 넣은 뒤에는 반드시 "새 index.html 만들기" 로 파일을 만들어야
     다른 폰에도 그 사진이 들어갑니다. (관리자 화면 맨 위 노란 경고 참고)
 · 브라우저 데이터 삭제 / 앱 삭제 후 재설치 시 폰에 저장된 내용은 사라집니다.
   중요한 세팅은 아래 5번으로 꼭 백업해 두세요.

----------------------------------------------------
5. 백업 / 복원 · 다른 폰에도 같은 내용으로 배포하기  ★ 중요
----------------------------------------------------
 관리자 화면 위쪽 "백업 / 복원" 칸에 버튼 3개가 있습니다.

 (1) 내보내기 (파일 저장)
     지금 내용 전부(게시물·사용자·DM·스토리·로고)를
     단서인스타_백업.json 파일로 저장합니다.

 (2) 불러오기 (파일 열기)
     위에서 저장한 json 을 골라 그대로 되돌립니다.
     새 파일을 설치해 내용이 초기화된 뒤에도 이걸로 살릴 수 있습니다.

 [사진이 안 보일 때 — 먼저 여기부터 확인]
     "백업 / 복원" 칸 안에 "사진 확인" 상자가 있습니다.

       지금 화면에 든 이미지   : 12개   ← 내가 넣은 사진
       지금 열려 있는 파일에 든 이미지 : 1개  ← 실제 배포된 파일 안의 사진

     두 숫자가 다르면 "사진이 파일에 아직 안 들어갔습니다" 라고 빨갛게 뜹니다.
     이때는 아래 (3) 으로 새 파일을 만들어 그 파일을 올려야 합니다.
     폰에서 이 상자를 보면, 지금 그 폰에 깔린 파일에 사진이 들어있는지
     바로 알 수 있습니다.

 (3) 새 index.html 만들기   ← 다른 폰에 같은 내용으로 설치할 때
     지금 내용을 그대로 안에 담은 index.html 을 새로 만들어 줍니다.
     · 이 파일로 폴더의 index.html 을 덮어쓰세요.
     · 그 폴더를 다른 폰에 설치하면 내용이 그대로 들어갑니다.
     · 만들 때마다 DATA_VERSION 이 새 시각으로 바뀌므로,
       이미 설치된 폰들도 다음 실행 때 새 내용으로 갈아끼워집니다.
     ※ 폰에서 바로 만들면 "다운로드" 폴더에 저장됩니다.
       PC 로 옮겨 폴더의 index.html 과 바꾼 뒤 다시 배포하세요.
     ※ 만들면 "새 index.html 저장됨 · 사진 12장 · 3.4MB" 처럼 뜹니다.
       사진 개수가 0 이거나 예상보다 적으면 경고가 먼저 뜨니 확인하세요.
     ※ ★ 가장 흔한 실수 : 다운로드된 index.html 대신, 폴더에 원래 있던
       index.html 을 그대로 올리는 것입니다. 반드시 "방금 다운로드된 파일"로
       폴더의 index.html 을 덮어쓴 뒤 업로드하세요.
     ※ 사진을 넣은 기기에서 파일을 만들어야 합니다.
       (폰에서 사진을 넣었다면 그 폰에서 만들어야 사진이 들어갑니다)

 [권장 순서]
   PC/폰에서 내용을 다 넣는다
     → "새 index.html 만들기"
     → 폴더의 index.html 을 그 파일로 교체
     → 폴더를 Netlify 에 올리거나 각 폰에 복사해서 설치
   이렇게 하면 폰마다 따로 입력할 필요가 없습니다.

6. 처음 상태로 되돌리기
----------------------------------------------------
 주소 끝에 ?reset=1 을 붙여서 한 번 엽니다.
   예) http://localhost:8080/index.html?reset=1
 폰에 저장된 내용과 캐시, 서비스워커가 모두 지워지고
 파일에 들어있는 내용으로 다시 시작합니다.
 ※ 되돌리기 전에 5번 "내보내기" 로 백업해 두세요.

----------------------------------------------------
7. 파일을 새로 받았을 때
----------------------------------------------------
 index.html 을 새 파일로 교체하면 됩니다.
 홈 화면 아이콘으로 다시 열면 최신 파일을 먼저 확인해서 받아옵니다.
 (그래도 예전 화면이 보이면 위 6번의 ?reset=1 로 한 번 열어주세요)

 · DATA_VERSION 이 바뀐 파일이면 폰에 저장돼 있던 내용은 지워지고
   새 파일의 내용으로 시작합니다. (예전 캐시도 함께 정리됩니다)
   폰에서 고친 내용을 살리려면 먼저 "내보내기" 로 백업한 뒤,
   새 파일을 연 다음 "불러오기" 로 되돌리세요.

8. 자주 겪는 문제
----------------------------------------------------
 · "앱 설치" 메뉴가 안 보인다
   → IP 주소(192.168.x.x)로 열었을 가능성이 높습니다. localhost 로 여세요.
   → 이미 설치된 아이콘이 있으면 메뉴가 안 뜹니다. 기존 아이콘 삭제 후 재시도.

 · 로고가 기본 필기체로 나온다
   → logo.png 파일 이름과 위치를 확인하세요 (index.html 과 같은 폴더).
   → 관리자 모드 > 상단 로고 이미지 에서 직접 올려도 됩니다.

 · 내용을 고쳤는데 다른 폰에는 안 보인다
   → 고친 내용은 그 폰에만 저장됩니다. 5번 "새 index.html 만들기" 로
     파일을 새로 만들어 배포해야 다른 폰에도 들어갑니다.

 · 하단 탭바가 폰 메뉴바에 가린다
   → 관리자 모드 맨 위 "하단 여백" 숫자를 24~48 정도로 키우고 저장하세요.

 · 스토리를 눌러도 안 열린다
   → 그 인물에게 스토리 사진이 없는 경우입니다(회색 링). 정상 동작입니다.
     관리자 > 스토리 탭에서 사진을 넣으면 무지개 링으로 바뀝니다.
